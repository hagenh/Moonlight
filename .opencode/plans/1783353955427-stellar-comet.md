# Day-Night Cycle + Sleep System Implementation Plan

## Overview
- Visual day-night cycle via Global Light2D color/intensity lerping
- Bed interactable on the street (placeholder)
- Forced sleep at 22:00 curfew
- Ordered sleep-tick pipeline: ferment → income → heat decay → (stubs for Elias/move-in/autosave)

---

## Files to Create

### 1. `Assets/Scripts/DayNightLighting.cs`
MonoBehaviour referencing the Global Light2D. Lerps color + intensity per frame based on `TimeManager.Hour + Minute/60f`.

**Color keyframes:**
| Hour | Color | Intensity |
|------|-------|-----------|
| 6 (dawn) | Warm amber (1.0, 0.8, 0.6) | 0.6 |
| 8 (morning) | Warm white (1.0, 0.95, 0.85) | 0.85 |
| 12 (noon) | Pure white (1.0, 1.0, 1.0) | 1.0 |
| 16 (afternoon) | Slightly warm (1.0, 0.93, 0.8) | 0.9 |
| 19 (dusk) | Orange sunset (1.0, 0.6, 0.3) | 0.6 |
| 21 (late dusk) | Deep purple (0.4, 0.3, 0.6) | 0.35 |
| 22+ (night) | Deep blue (0.15, 0.15, 0.35) | 0.25 |

Interpolate linearly between adjacent keyframes. Use a sorted array of `(hour, color, intensity)` tuples and find the surrounding pair each frame.

Serialized fields: `Light2D globalLight`, configurable keyframes.

### 2. `Assets/Scripts/SleepManager.cs`
Singleton MonoBehaviour. Runs the ordered pipeline.

**`BeginSleep()` method (called by Bed.Interact() or forced curfew):**
1. Freeze player (`IsMenuOpen = true`)
2. Show fade-to-black overlay (simple Canvas Image with alpha tween)
3. Fire `GameEvents.OnSleepInitiated(day)`
4. Call `TimeManager.AdvanceToDayEnd()` — this advances time, fires `OnDayEnded` (→ income + seller cleanup), fires `OnHourChanged`
5. Apply heat decay: `GameManager.Instance.AddHeat(-decayAmount)` (default -5)
6. Stub: move-in checks (log only, no action)
7. Stub: autosave (log only, no action)
8. Fire `GameEvents.OnSleepCompleted(newDay)`
9. Fade from black
10. Unfreeze player (`IsMenuOpen = false`)

**Fade overlay:** A simple black Canvas Image that tweens alpha 0→1 over ~0.5s, then 1→0 after the pipeline runs. Can be a child of the SleepManager or a separate component.

### 3. `Assets/Scripts/Bed.cs`
`IInteractable` with `InteractType.Bed`. Simple placeholder.

- `Interact()` → calls `SleepManager.Instance.BeginSleep()`
- No special state tracking
