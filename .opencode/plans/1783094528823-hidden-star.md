# Player Controller FSM Plan

## Overview
2D top-down player controller using a class-hierarchy finite state machine. Supports 8-directional movement with 4-way facing for animation. Includes animation trigger hooks (null-safe). Extensible for future states (Attack, Interact, Crouch). Input events drive transitions directly via virtual methods on states - no cached booleans.

## States: Idle <-> Move <-> Sprint

```
              +--------+
              |  Idle  |
              +--------+
             /          \
    Move+   /            \  Move-
  no Sprint/              \
          /                \
 +--------+  Sprint held  +--------+
 |  Move  |-------------->| Sprint |
 +--------+<--------------+--------+
   |    ^    Sprint         |    ^
   |    |    released       |    |
   +----+-------------------+----+
        Move- (input released) -> Idle
```

## File Structure

```
Assets/Scripts/Player/
  PlayerController.cs          MonoBehaviour - FSM owner, subscribes to input events, routes to current state
  AnimatorParams.cs            Static class - pre-hashed animator parameter IDs
  Enums/
    FacingDirection.cs         Enum: Down=0, Up=1, Left=2, Right=3
    PlayerStateType.cs         Enum: Idle, Move, Sprint
  States/
    PlayerState.cs             Abstract base class with virtual input event methods
    IdleState.cs               Zeroes velocity, transitions on movement input
    MoveState.cs               Walks at walkSpeed, transitions on sprint/idle
    SprintState.cs             Runs at sprintSpeed, transitions on move/idle
```

**7 hand-written files.** Plus the auto-generated `InputSystem_Actions.cs`.

## Key Design Decisions

| Decision | Choice | Why |
|----------|--------|-----|
| Movement physics | Rigidbody2D (Dynamic, Gravity=0, Continuous, Freeze Rotation Z, Interpolate) | Collision with Tilemap walls, NPCs; Unity standard for 2D |
| Movement style | 8-directional, normalized | Diagonal not faster than cardinal; analog stick supported |
| Facing for animation | 4-way (Down/Up/Left/Right) | Pokemon convention; sprite sheets typically have 4 facings |
| Input to transitions | Event callbacks -> virtual methods on states | No cached booleans; events drive transitions directly; states own their logic |
| State instances | Pre-allocated dictionary in Awake | Zero GC during transitions |
| Animator calls | Through PlayerController helpers with null-checks | Works without Animator; "just works" when added later |
| Tunable fields | Serialized fields directly on PlayerController | Simple; no ScriptableObject overhead |

## Input Event Flow

PlayerController subscribes to Input System events and calls virtual methods on the current state. Only `MoveInput` (Vector2) is cached - needed by PhysicsUpdate for velocity.

```
InputSystem_Actions (generated)
       |
       v
PlayerController (subscribes to events)
       |
       v
CurrentState.OnMovePerformed(input)    -> state decides transition
CurrentState.OnMoveCanceled()          -> state decides transition
CurrentState.OnSprintPerformed()       -> state decides transition
CurrentState.OnSprintCanceled()        -> state decides transition
```

### PlayerController input subscriptions:
```
Move.performed   += ctx => { moveInput = ctx.ReadValue<Vector2>(); CurrentState.OnMovePerformed(moveInput); }
Move.canceled    += ctx => { moveInput = Vector2.zero; CurrentState.OnMoveCanceled(); }
Sprint.performed += ctx => CurrentState.OnSprintPerformed();
Sprint.canceled  += ctx => CurrentState.OnSprintCanceled();
```

### For future states, just add more virtual methods:
```
Attack.performed  += ctx => CurrentState.OnAttackPerformed();
Interact.performed += ctx => CurrentState.OnInteractPerformed();
Crouch.performed  += ctx => CurrentState.OnCrouchPerformed();
Crouch.canceled   += ctx => CurrentState.OnCrouchCanceled();
```

## Class Responsibilities

### PlayerController.cs (MonoBehaviour)
- **Serialized fields**: walkSpeed (4.0), sprintSpeed (7.0), moveDeadzone (0.1), animator (optional)
- **Awake**: Get Rigidbody2D, create InputSystem_Actions, subscribe to events, populate state dictionary, enter IdleState
- **OnEnable/OnDisable**: Enable/disable Player action map
- **OnDestroy**: Dispose InputSystem_Actions
- **Update**: Call currentState.LogicUpdate()
- **FixedUpdate**: Call currentState.PhysicsUpdate()
- **ChangeState(type)**: Exit current, lookup new from dictionary, Enter new (no-op if same state)
- **UpdateFacingDirection(input)**: Convert 8-dir input to nearest 4-dir FacingDirection via angle math
- **SetAnimatorTrigger/Float/Integer**: Null-check Animator then call through
- **CurrentState property**: Public getter for active state (used by input events to route to state)

### PlayerState.cs (abstract)
- Fields: `controller` (PlayerController)
- Abstract: Enter(), Exit(), LogicUpdate(), PhysicsUpdate(), StateType
- Virtual input methods (default no-op; override in states that care):
  - `OnMovePerformed(Vector2 input)` 
  - `OnMoveCanceled()`
  - `OnSprintPerformed()`
  - `OnSprintCanceled()`
- Helpers: ChangeState(), UpdateFacingDirection()

### IdleState
- Enter: trigger "Idle", zero velocity, zero speed floats
- OnMovePerformed(input): update facing, ChangeState(Sprint if Sprint.IsPressed else Move)
- PhysicsUpdate: hold velocity at zero

### MoveState
- Enter: trigger "Move"
- OnMoveCanceled(): ChangeState(Idle)
- OnSprintPerformed(): ChangeState(Sprint)
- LogicUpdate: update facing from moveInput
- PhysicsUpdate: velocity = moveInput.normalized * walkSpeed; set speed floats

### SprintState
- Enter: trigger "Sprint"
- OnMoveCanceled(): ChangeState(Idle)
- OnSprintCanceled(): ChangeState(Move) (still moving)
- LogicUpdate: update facing from moveInput
- PhysicsUpdate: velocity = moveInput.normalized * sprintSpeed; set speed floats

### AnimatorParams (static)
- FacingDirection (int), SpeedX (float), SpeedY (float), Idle (trigger), Move (trigger), Sprint (trigger)
- All as `Animator.StringToHash()` readonly ints

### Enums
- FacingDirection: Down=0, Up=1, Left=2, Right=3
- PlayerStateType: Idle, Move, Sprint

## Animation Parameter Layout (for when Animator is created)

| Parameter | Type | Set By |
|-----------|------|--------|
| FacingDirection | Int (0-3) | PlayerController.UpdateFacingDirection |
| SpeedX | Float | MoveState/SprintState PhysicsUpdate |
| SpeedY | Float | MoveState/SprintState PhysicsUpdate |
| Idle | Trigger | IdleState.Enter |
| Move | Trigger | MoveState.Enter |
| Sprint | Trigger | SprintState.Enter |
