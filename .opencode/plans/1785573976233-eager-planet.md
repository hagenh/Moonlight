# Plan: Replace Building_Sprites Child with Single Combined Sprite

## Goal

Replace the `Building_Sprites` child GameObject (42 individual sprite tiles) with a single combined sprite on the Building root's SpriteRenderer. Remove both the `Building_Sprites` and `Square` child GameObjects.

## Current Structure

```
Building (root)                          [Layer 6]
  ├── Square                             [INACTIVE, SpriteRenderer, scale 4x]
  ├── Spot Light 2D (1)                  [window light]
  ├── Spot Light 2D (2)                  [window light]
  ├── Canvas / DevLabel                  [debug label]
  ├── Building_Sprites                   [INACTIVE, scale 0.5x, 42 tile children]
  │   ├── Town 2 Color 2@128x128_2      (0, 0)
  │   ├── Town 2 Color 2@128x128_3      (1, 0)
  │   ├── ... (40 more tiles)
  │   └── Town 2 Color 2@128x128_117    (3, -7)
  └── BuildingPreBuildingStage (prefab)  [preBuildVisual]
```

- Source atlas: `Assets/Sprite/2D Hand Painted - Town Tileset/128x128/Town 2 Color 2@128x128.png` (2048x2048, PPU 128, 16x16 grid of 128px tiles)
- `Building_Sprites` parent: position (-0.5, 1.75, 0), scale (0.5, 0.5, 1)
- Tile grid bounds: x in [-2, 4], y in [0, -7] (7 columns, 8 rows, 42 of 56 cells filled)
- Material: URP 2D Lit (`a97c105638bdf8b4a8650670310a4cd3`)
- `facadeRenderer` references the Square's SpriteRenderer (inactive, color tinting has no visual effect)
- `buildingSprites` toggled active/inactive in `Building.RefreshVisuals()`
- No code iterates Building_Sprites children; `buildingSprites` is treated as an opaque `GameObject`

## World Scale Math

Current visual extent (relative to Building root):
- Width: 7 tiles x 0.5 scale = 3.5 world units
- Height: 8 tiles x 0.5 scale = 4.0 world units
- Center: (0, 0) relative to Building root

Combined sprite: 7 cols x 8 rows x 128px = 896 x 1024 pixels
- PPU 256: 896/256 = 3.5 x 1024/256 = 4.0 world units (1:1 match)
- Pivot (0.5, 0.5) centers sprite on Building root → same visual position as current layout

## Step 1: Create Python Merge Script

**File:** `Tools/merge_building_sprites.py`

Follow the existing `Tools/merge_prebuild.py` pattern. The script:
1. Reads the source atlas
2. Defines all 42 children as `(grid_x, grid_y, sprite_id)`
3. Calculates bounding box (min_x=-2, max_x=4, min_y=-7, max_y=0)
4. Creates 896x1024 output image
5. For each child, computes atlas source coords using formula: `x = (id % 16) * 128`, `y = 1920 - (id // 16) * 128` (then converts to PIL top-left origin)
6. Pastes tiles at correct output positions
7. Saves to `Assets/Sprite/BuildingFacade.png`

## Step 4: Modify Building.cs

**File:** `Assets/Scripts/Building.cs`

Changes:
1. Remove `[SerializeField] private GameObject buildingSprites;` field
2. In `RefreshVisuals()`, replace `buildingSprites.SetActive(!isAbandoned)` with `facadeRenderer.enabled = !isAbandoned`
3. Keep `facadeRenderer.color = ...` as-is (tinting will now be visible for the first time)

```csharp
private void RefreshVisuals()
{
    if (windowLights != null)
        foreach (var light in windowLights)
            light.enabled = State == BuildingState.Restored;

    bool isAbandoned = State == BuildingState.Abandoned;
    if (preBuildVisual != null)
        preBuildVisual.SetActive(isAbandoned);
    if (facadeRenderer != null)
        facadeRenderer.enabled = !isAbandoned;

    if (facadeRenderer != null)
        facadeRenderer.color = State switch
        {
            BuildingState.Abandoned => new Color(0.55f, 0.45f, 0.65f),
            BuildingState.Purchased => new Color(0.75f, 0.55f, 0.35f),
            BuildingState.Cleared => new Color(0.4f, 0.8f, 0.55f),
            BuildingState.Restored => new Color(1f, 0.85f, 0.4f),
            _ => Color.white
        };
}
```
