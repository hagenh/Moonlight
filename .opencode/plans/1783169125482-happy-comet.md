# Complete the Interact State

## Overview
Complete the `InteractState` so the player can interact with buildings and other machines. The interaction is **instant** (call `Interact()` and return to idle), but the **detection runs continuously** every frame to support proximity prompts like "Press E to interact."

## Key Design Decision: Continuous `Physics2D.OverlapBoxAll` in PlayerController

Instead of spawning a collider or checking only on button press, `PlayerController.Update()` runs `Physics2D.OverlapBoxAll()` every frame and stores the result in `CurrentInteractable`. This enables:

- **Proximity prompts**: UI or interactable objects can read `player.CurrentInteractable` to show/hide "Press E" text
- **Instant interaction**: When E is pressed, InteractState reads `CurrentInteractable`, calls `Interact()`, and exits immediately

The existing `interactCollider` field is replaced with a simple `Vector2 interactBoxSize` since we only need dimensions, not a prefab instance.

## Changes

### 1. New file: `Assets/Scripts/IInteractable.cs`
Create an interface that all interactable objects implement:
```csharp
public interface IInteractable
{
    void Interact();
}
```

### 2. Modify: `Assets/Scripts/Building.cs`
- Implement `IInteractable`
- Replace `const` fields with instance fields (so different buildings can have different values)
- Add a stub `Interact()` method
- Remove empty `Start()`/`Update()`

### 3. Modify: `Assets/Scripts/Player/PlayerController.cs`
- Replace `public BoxCollider2D interactCollider` with:
  - `[SerializeField] private Vector2 interactBoxSize = new Vector2(1, 1);`
  - `[SerializeField] private LayerMask interactableLayer;`
- Add `public IInteractable CurrentInteractable { get; private set; }`
- Add a private method `UpdateInteractDetection()` that:
  - Calculates the box center offset based on `facingDirection` (1 unit ahead)
  - Calls `Physics2D.OverlapBoxAll(center, interactBoxSize, 0f, interactableLayer)`
  - Finds the first `IInteractable` component on any hit collider
  - Sets `CurrentInteractable` (or null if nothing found)
- Call `UpdateInteractDetection()` in `Update()` (before `currentState.LogicUpdate()`)
- Expose `InteractBoxSize` and `InteractableLayer` as properties for InteractState
- Fix `OnInteract` bug: remove the `context.canceled` branch that calls `OnInteractPerformed()` again
- Remove `InstantiateFromPlayer` method (no longer needed)

### 4. Modify: `Assets/Scripts/Player/States/InteractState.cs`
Complete rewrite. The state is instant:
- **`Enter()`**: Read `controller.CurrentInteractable`, if non-null call `Interact()`, then immediately `ChangeState(new IdleState(controller))`
- **`Exit()`**: No-op
- **`LogicUpdate()`**: No-op (state exits in Enter, this should never run)
- **`PhysicsUpdate()`**: No-op
- Remove `_collider` field and `CalculateInteractColliderPos()` — detection is now in PlayerController
- Remove unused `using System;` and `using System.Diagnostics;`

### 5. Modify: `Assets/Scripts/Player/States/IdleState.cs`
- Add `using Player.States;` import
- Add `OnInteractPerformed()` override that transitions to `InteractState`

### 6. Modify: `Assets/Scripts/Player/AnimatorParams.cs`
- Add `Interact` trigger hash (for future animation support)

2. Set `Interact Box Size` (e.g., `1, 1`)
3. Assign the Bakery GameObject to the "Interactable" layer
4. The Bakery's existing `BoxCollider2D` must have `isTrigger = true` so the overlap check can detect it

## Future: Proximity Prompts
With `CurrentInteractable` exposed, a future prompt system can:
- Add a script to interactable objects that checks `player.CurrentInteractable == this` to show/hide a world-space "Press E" canvas
- Or add a UI manager that reads `CurrentInteractable` each frame to toggle a prompt
