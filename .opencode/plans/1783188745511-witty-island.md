## Recommended Implementation Order

### Step 1: BuildingManager (`Assets/Scripts/BuildingManager.cs`)

Create a manager that:
- Holds a `List<Building>` of all buildings in the scene
- Provides `TryPurchase(Building)`, `TryRepair(Building)`, `CollectIncome(Building)` — all go through the manager
- Fires `GameEvents.OnBuildingStateChanged` (move this out of `Building.cs`)
- `Building.cs` becomes a "dumb prefab" — holds data (name, costs, income, state), renders visuals, but doesn't mutate its own state

**Files to modify:**
- `Assets/Scripts/Building.cs` — remove `TryPurchase`, `TryRepair`, `CollectIncome`; `Interact()` calls `BuildingManager` methods instead
- New: `Assets/Scripts/BuildingManager.cs`

### Step 2: Building.prefab Upgrades

Update `Building.prefab` with:
- **Door trigger collider** (BoxCollider2D, isTrigger, positioned at building entrance)
- **Light2D per window** (Point Light2D, disabled by default, enabled when state = Restored)
- **Dev label** (TextMeshPro or world-space text showing name/state/price)

**Files to modify:**
- `Assets/Scripts/Building.cs` — add `OnBuildingStateChanged` handler to toggle Light2D and update dev label based on state

### Step 3: Tilemap Setup

In `SampleScene.unity` (or a new `Street.unity` scene):
- Create 3 Tilemap layers: Ground, Collision, Overhead (with sorting layers)
- Paint placeholder tiles using the imported tilesets
- Add TilemapCollider2D on the Collision layer
- Position 6 Building instances along the street

This is primarily a Unity Editor task, but the scripts need to support it (collision layers, sorting orders).

### Step 4: Purchase Juice

- Add a simple scale-punch animation on purchase (DOTween or hand-rolled coroutine)
- Placeholder SFX (even a default Unity beep)

**Files to modify:**
- `Assets/Scripts/Building.cs` — add `PunchScale()` coroutine triggered on state change

## Verification
