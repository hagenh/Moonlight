# LAMPLIGHT (Moonlighter folder) — Test Suite Plan

**Project:** Unity 6.2.14f1, 2D/URP, InputSystem 1.16.0, Test Framework 1.6.0 (NUnit + `UnityEngine.TestTools`).
**Current state:** ~41 hand-written C# files in `Assets/Scripts/`, all compiling into default `Assembly-CSharp`. **Zero tests, zero `.asmdef` files.** Test framework package is installed but unused.

**Decisions (confirmed with user):**
1. **Refactor for testability** — extract pure rule classes out of singleton MonoBehaviours + add small seams (`IRng`, time source). Singletons delegate to pure classes and remain the only place that fires `GameEvents`; behavior is unchanged.
2. **Foundation + core loops now, roadmap for the rest.** Core loops: Economy/Cash, Inventory, Selling, Building Renovation, Fermentation, Time, Sleep ordering.
3. **Heavy PlayMode** — PlayMode integration tests for end-to-end loops (real MonoBehaviours, coroutines, frames); EditMode unit tests for the extracted pure logic (fast, deterministic).

---

## Architecture contract for every extraction

- The **pure class** owns state/rules, returns data (bools / old-new values / decisions), fires **no** `GameEvents`, has **no** Unity dependency beyond `Mathf`/`Mathf.Clamp01` where exact parity matters (EditMode-safe).
- The **singleton MonoBehaviour** owns a private pure-class instance, delegates to it, and is the **only** place that fires `GameEvents` / touches other singletons. Existing public API of the singleton is preserved verbatim so all callers (UI, other managers, `DebugMenu`) keep working unchanged.
- **Verify the game still runs after every refactor** (play in editor, exercise the `DebugMenu` P-key which drives every system).

**UTF 1.6 mechanism (precise):** there is **no "Test Assemblies" checkbox** in Unity 6. An asmdef is recognized as a test assembly when it references `UnityEngine.TestRunner`/`UnityEditor.TestRunner`. NUnit is a precompiled DLL — to expose it, set `overrideReferences: true` and list `"nunit.framework.dll"` in `precompiledReferences`. `includePlatforms: ["Editor"]` keeps tests + NUnit out of player builds.

### 0.5 Shared test helpers (`Assets/Tests/Shared/`)
- **`GameEventsReset.cs`** — `ClearAll()`: uses reflection to null every static event backing field on `GameEvents` (iterate `typeof(GameEvents).GetFields(BindingFlags.NonPublic|BindingFlags.Static)`, `SetValue(null, null)`). This avoids modifying `GameEvents.cs` at all and auto-handles future events. Called in every `[TearDown]`/`[UnityTearDown]`.
- **`TestBootstrap.cs`** — `CreateSingleton<T>() where T:MonoBehaviour` → `new GameObject(typeof(T).Name).AddComponent<T>()` (Awake runs, sets `Instance`). `DestroyAll(params GameObject[])` → `UnityEngine.Object.DestroyImmediate`/`Destroy`. `ResetSingletons()` helper that destroys the 11 known singletons and nulls their static `Instance` (via the destroy path; Instance clears because Awake guard pattern won't re-run, so also explicitly null via reflection or a `Reset()` hook where present).
- **`Fakes/StubRng.cs`** — `IRng` with scripted `Value01()`/`Range()` queue for deterministic confiscation/scheduling tests.
- **`Fakes/SeededRng.cs`** — `IRng` wrapping `System.Random` for reproducible sequences.
- **`EventRecorder.cs`** — subscribes to specified `GameEvents`, records invocation order + payloads into a list; used by the Sleep ordering test.
- **Verify Phase 0:** add one trivial EditMode test (`Assets/Tests/EditMode/SmokeTest.cs`) with `[Test] public void FrameworkWorks() => Assert.Pass();` and run via **Window > General > Test Runner**. Confirm it discovers and passes.

## Phase 1 — Refactors (one system at a time; game stays green after each)

New pure classes go in a `Assets/Scripts/Rules/` subfolder (grouped, not cluttering the flat root), except `FacingMath` which goes in `Assets/Scripts/Player/`.

### 1.1 `EconomyState` ← `GameManager.cs`
- **New:** `Assets/Scripts/Rules/EconomyState.cs` — plain C# (only `System`).
  - `Cash/Heat/Reputation` (private set), ctor `EconomyState(int startingCash)`.
  - `bool TrySpend(int amount)` — `if (Cash < amount) return false; Cash -= amount; return true;` (preserves current behavior incl. the latent quirk that `TrySpend(negative)` adds cash — document with a characterization test, do not "fix").
  - `void AddCash(int amount)`.
  - `int SetHeat(int value)` / `int AddHeat(int delta)` — `Heat = System.Math.Max(0, value)`; **return old value** so singleton fires events only-if-changed.
  - `int SetReputation(int value)` — returns old.
- **`GameManager.cs` delegation:** `private EconomyState _economy;` init in Awake (`_economy = new EconomyState(startingCash)`). Getters → `_economy.*`. `TrySpend` → delegate then `GameEvents.OnCashChanged(Cash)`. `SetHeat`/`SetReputation` → `int old = _economy.SetX(...); if (X != old) GameEvents.OnXChanged(X, old);`. **Exact parity** with current `Mathf.Max(0,…)` clamp and only-fire-if-changed guards (verified in source lines 39-51).
- **Verify:** Play, use DebugMenu to grant cash / set heat / set rep; confirm HUD updates identically.

### 1.2 `Inventory` ← `InventoryManager.cs`
- **New:** `Assets/Scripts/Rules/Inventory.cs` — plain C# (`System.Collections.Generic`; `ItemDef` is already a pure POCO).
  - `Dictionary<ItemDef,int> _items`; `IReadOnlyDictionary<ItemDef,int> AllItems`; `int GetCount(ItemDef)` (null→0); `bool Has(ItemDef,int)`.
  - `MutResult TryAdd(ItemDef, int)` / `MutResult TryRemove(ItemDef, int)` returning `(bool Success, int OldCount, int NewCount)`.
  - Edge cases verified against source: TryAdd rejects null/`<=0`; TryRemove rejects null/`<=0`, then insufficient→fail; on success subtract and **auto-remove zero entry**; `newVal = GetValueOrDefault(def,0)`.
- **`InventoryManager.cs` delegation:** `private readonly Inventory _inventory = new();`; `GetCount`/`Has`/`AllItems` delegate. `TryAdd` → `var r = _inventory.TryAdd(...); if(!r.Success) return false; GameEvents.OnInventoryChanged(def,r.OldCount,r.NewCount); GameEvents.OnToastRequested($"+{count} {def.displayName}"); return true;`. `TryRemove` → preserve exact toast order: null/<=0 → `return false` (no toast); insufficient → "Not enough {displayName}" toast + `return false`; success → `OnInventoryChanged` (no success toast on remove). **Exact parity** with source lines 33-58.
- **Verify:** Play, grant items via DebugMenu, check HUD inventory list; sell items; confirm toasts.

### 1.3 `IRng` seam + `EconomyRules` ← `SellManager.cs` (and fix `SellUI` logic leak)
- **New:** `Assets/Scripts/Rules/IRng.cs` — `interface IRng { float Value01(); int Range(int minInclusive, int maxExclusive); float Range(float min, float max); }`.
- **New:** `Assets/Scripts/Rules/UnityRng.cs` — `sealed class UnityRng : IRng` (static `Instance`) wrapping `UnityEngine.Random` (`Range(int,min,maxExclusive)` matches Unity's maxExclusive semantics; `Range(min,max+1)` is used to simulate inclusive ranges).
- **New:** `Assets/Scripts/Rules/EconomyRules.cs` — pure static:
  - `GetSellPrice(ItemDef, SellerType)` → `Mathf.RoundToInt(item.basePrice * (seller==RiskyBuyer?2f:1f))`.
  - `GetBuyPrice(ItemDef)` → `item.basePrice`.
  - `IsCartDay(int day)` → `day % 3 != 0`.
  - `IsSellable(ItemDef, SellerType)` → `seller==TravelingCart ? item.isBottle : !item.isIngredient` (migrated from `SellUI.IsSellable` — fixes the logic leak).
  - `ShouldConfiscate(int currentHeat, IRng)` → `currentHeat > 50 && rng.Value01() < 0.1f` (strictly `> 50`, verified source line 143).
  - `RiskyBuyerAppearsToday(IRng, float chance)` / `PickHour(IRng, int minIncl, int maxIncl)` helpers.
- **`SellManager.cs` seam + delegation:** add `private IRng _rng = UnityRng.Instance;` and `internal void SetRng(IRng rng) => _rng = rng;`. `GetSellPrice`/`GetBuyPrice`/`IsCartDay` delegate to `EconomyRules`. `PlanTomorrow` uses `EconomyRules.PickHour(_rng, tormodArriveMin, tormodArriveMax)` and `EconomyRules.RiskyBuyerAppearsToday(_rng, riskyBuyerChance)`. `ExecuteSale` confiscation branch → `if (seller==RiskyBuyer && EconomyRules.ShouldConfiscate(GameManager.Instance.Heat, _rng)) { … TryRemove; toast "Confiscated! Items seized."; AddHeat(15); return true; }`. **Note:** both confiscation and normal RiskyBuyer sale add `+15` heat (verified lines 147 & 158).
- **`SellUI.cs` line 177:** replace `IsSellable` body with `EconomyRules.IsSellable(item, _currentSeller!.Value)`.
- **Verify:** Play to a cart day and a risky-buyer day; sell items; confirm prices, toasts, heat changes match prior behavior.
