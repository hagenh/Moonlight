# Stealth Delivery + Economy Rework

## Vision
Selling moonshine is now a physical stealth run. You fill a crate at the vat (inside the bakery), carry it out to the street, and navigate past **guard vision cones** to reach a delivery point — hiding behind buildings for cover. If caught carrying, you bribe or eat a suspicion spike. No more menu-based selling, no more 3-seller model, no more Constable.

**Guards, not residents.** Residents (Berta, future NPCs) are pure positive — dialogue, income, recipe unlocks. Guards are a separate threat that patrols the street with vision cones. Guard count scales with suspicion: play clean = few guards, play hot = more eyes on the street.

## Core loop
1. Ferment moonshine inside bakery (safe, interior)
2. Collect vat output as a **Crate** (physical carry object, normal speed)
3. Exit bakery to street (now exposed to guard patrols)
4. Navigate past **guard vision cones** to delivery point (hide behind buildings)
5. Deposit crate at **DeliveryPoint** for payment
6. Risk: if seen carrying → detection fills → caught → bribe or suspicion spike

## Why this works
- Buildings have solid 4x4 `BoxCollider2D` body colliders — perfect cover for raycast checks.
- The carry system (`CarryState`, `PickUp`/`Drop`/`Deposit`) is directly reusable from debris.
- Camera is parented to player — no camera work needed for outdoor stealth.
- Guards are decoupled from residents — adding NPCs never makes the game harder.
- Guard scaling creates dynamic difficulty: low suspicion = 1 lazy guard, high suspicion = multiple tight patrols.

### `Assets/Scripts/Guard.cs`
Patrol NPC with vision cone. Separate from `Resident` — no dialogue, no schedule, just waypoints + detection.

```csharp
public class Guard : MonoBehaviour
{
    [Header("Patrol")]
    [SerializeField] private Transform[] waypoints;
    [SerializeField] private float walkSpeed = 1.5f;
    [SerializeField] private float pauseAtWaypoint = 2f;

    [Header("Vision")]
    [SerializeField] private float visionRange = 6f;
    [SerializeField] private float visionHalfAngle = 35f;     // 70° cone
    [SerializeField] private float sweepAmplitude = 25f;      // ±25° sweep
    [SerializeField] private float sweepSpeed = 0.4f;         // sweeps/sec
    [SerializeField] private float detectionRate = 60f;       // detection/sec to fill
    [SerializeField] private float detectionDecay = 40f;      // drain/sec when safe

    [Header("Bribe")]
    [SerializeField] private int bribeCost = 50;
    [SerializeField] private int suspicionOnBribe = 5;
    [SerializeField] private int suspicionOnCaught = 20;
    [SerializeField] private float lookAwayDuration = 8f;     // after bribe, guard "looks away"

    private int _currentWaypoint;
    private bool _pausing;
    private float _pauseTimer;
    private float _detection;       // 0-100
    private bool _caught;
    private bool _lookingAway;
    private float _lookAwayTimer;
    private float _baseFacing;      // direction facing (updated from patrol movement)
    private GameObject _coneObject;
    private MeshFilter _coneMeshFilter;
    private MeshRenderer _coneRenderer;
    private Material _coneMaterial;

    // Awake: create cone child GameObject (mesh + renderer + material), generate cone mesh
    // Update:
    //   1. Patrol: if !_pausing, move toward waypoints[_currentWaypoint]. When reached, _pausing=true, timer=pauseAtWaypoint. Update _baseFacing from movement direction.
    //   2. If _pausing: count down. When done, advance waypoint, _pausing=false.
    //   3. If _lookingAway: count down, skip detection, cone alpha=0.05. When done, _lookingAway=false.
    //   4. Sweep: currentFacing = _baseFacing + sin(time * sweepSpeed) * sweepAmplitude (only when pausing; when walking, facing = movement dir, no sweep)
    //   5. Rotate cone mesh to currentFacing
    //   6. CheckDetection(): if player carrying crate AND in cone AND no cover → fill detection. Else drain.
    //   7. If detection >= 100 AND !_caught → TriggerCaught()
    //   8. Update cone color by detection (yellow → orange → red)

    // CheckDetection:
    //   - If PlayerController.Instance is null or !IsCarryingCrate → drain, return
    //   - Vector2 to player, distance check (> visionRange → drain, return)
    //   - Angle check (delta > visionHalfAngle → drain, return)
    //   - Cover check: Physics2D.RaycastAll from guard toward player, skip triggers, if any Building collider closer than player → drain, return
    //   - All pass → fill detection

    // TriggerCaught:
    //   - _caught = true, fire GameEvents.OnCaughtBribe(bribeCost)
    //   - BribeUI shows: "Guard caught you! Pay {cost}g?"
    //   - [E] Pay: TrySpend, AddHeat(suspicionOnBribe), _lookingAway=true, _caught=false
    //   - [Q] Refuse: AddHeat(suspicionOnCaught), _caught=false
    //   - Player locked (IsMenuOpen) during bribe

    // Cone mesh: fan of triangles, 16 segments, origin + 17 arc points
    // Material: Sprites/Default shader with transparency
    // Color: new Color(1, 1, 0.3f, 0.12f) safe → new Color(1, 0.3f, 0.1f, 0.4f) detected

    private bool IsBlockedByCover(Vector2 from, Vector2 to)
    {
        Vector2 dir = (to - from).normalized;
        float dist = Vector2.Distance(from, to);
        var hits = Physics2D.RaycastAll(from, dir, dist);
        foreach (var hit in hits)
        {
            if (hit.collider.isTrigger) continue;
            if (hit.collider.GetComponentInParent<Building>() != null) return true;
        }
        return false;
    }
}
```

### `Assets/Scripts/DeliveryPoint.cs`
Mirrors `DebrisPile`. Pays on deposit, applies suspicion.

```csharp
public enum DeliveryType { Cart, Backwoods }

public class DeliveryPoint : MonoBehaviour, IInteractable
{
    public DeliveryType deliveryType;
    public InteractType InteractType => InteractType.DeliveryPoint;

    public void Interact()
    {
        if (!PlayerController.Instance.IsCarryingCrate) { toast "Nothing to deliver"; return; }
        var crate = PlayerController.Instance.CarriedCrate;
        int heat = GameManager.Instance.Heat;
        int price = EconomyRules.GetDeliveryPrice(crate.item, deliveryType, heat) * crate.count;
        GameManager.Instance.AddCash(price);
        toast $"+{price}g";
        if (deliveryType == DeliveryType.Backwoods)
            GameManager.Instance.AddHeat(EconomyRules.GetSuspicionForDrop(crate.item, TimeManager.Instance.Hour));
        Destroy(crate.gameObject);
        PlayerController.Instance.DropCrate();
        GameEvents.OnDeliveryMade(deliveryType, crate.item, crate.count, price);
    }
}
```
